# Black Vets Info Hub

A static resource hub for African American veterans and their families: benefits, health care, mental health, housing, jobs, education, legal help, heritage, and community organizations.

## Files
- `index.html` – page structure and content
- `styles.css` – design (navy / gold palette, responsive down to phone width)
- `script.js` – searchable, filterable resource directory. **Add or edit resources in the `RESOURCES` array at the top.**

## Run locally
Open `index.html` in a browser, or:

```bash
cd black-vets-hub && python3 -m http.server 8000
```

## Deploy
No build step. Drop the folder on GitHub Pages, Netlify, Vercel, or any static host.

## Before launch
- Click through every external link and confirm it still resolves.
- Confirm phone numbers against the official program pages.
- Swap in a real logo, photos, and your organization's contact info.
